# Site vitrine — Accompagnateur en moyenne montagne

Site personnel de Thomas : vision, histoire, aventures et projet d'accompagnateur en moyenne montagne (AMM).

## Où est quoi

```
site-amm/
├── index.html        Page d'accueil (textes et structure)
├── css/
│   └── style.css     Couleurs, polices, mise en page
├── js/
│   └── script.js     Menu, animations, filtre des randonnées
└── assets/
    ├── images/       Photos du site
    └── videos/       Vidéos du site
```

## Charte graphique

| Couleur | Code | Usage |
|---|---|---|
| Sable | `#E8DFCC` | Fonds clairs |
| Nuit | `#2D4654` | Titres, fonds sombres |
| Mousse | `#58664C` | Section projet, accents |
| Terre | `#8C6239` | Détails, mots en italique |

Elles sont définies tout en haut de `css/style.css` : pour changer une couleur, c'est là.

## Voir le site en local

Dans VS Code : clic droit sur `index.html`, puis **Open with Live Server**.

## Routine de travail

- **Début de journée** : *Sync Changes* pour récupérer le travail le plus récent.
- **Fin de journée** : `Cmd + S`, puis Source Control → message → **Commit** → **Sync Changes**.
